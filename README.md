# Публикация сайта-расписания

В этой папке хранятся манифест, офлайн-кэш и иконки PWA. При сборке они вместе с актуальным HTML попадут в `outputs/releases/<версия>/site/`.

Чтобы обновить GitHub Pages, распакуйте содержимое архива сайта в публикуемую папку репозитория `vasileveldar/schedule` и отправьте изменения в GitHub. `index.html`, `service-worker.js`, `manifest.webmanifest` и PNG-иконки должны лежать рядом. GitHub Pages откроет сайт по HTTPS, зарегистрирует офлайн-кэш после первого подключения к сети и сможет обновлять его при последующих посещениях.

На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран „Домой“». Safari возьмёт значок из `apple-touch-icon.png`. На Android Chrome предложит установить сайт как приложение после загрузки сайта.
