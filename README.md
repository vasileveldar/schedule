# Публикация расписания ИН-25-1

Этот форк создан от GitHub-ветки `main` и сохраняет её оформление v2. Он добавляет отдельный поиск, отображение текущей и следующей пары, а также напоминания только в Android-приложении. Серверная база пока не подключена.

## Публикация на GitHub Pages

1. Распакуйте архив и загрузите все файлы из него в публикуемую папку репозитория `vasileveldar/schedule`.
2. Отправьте изменения в GitHub и дождитесь публикации GitHub Pages.
3. Откройте сайт по HTTPS. После первой загрузки сервис-воркер сохранит страницу и основные ресурсы для работы офлайн.

Если сайт уже установлен на телефоне, откройте его онлайн один раз, чтобы браузер получил новую версию.

## Экспериментальная Android-сборка

Ветка `experiment/android-full-app` добавляет отдельный Android-пакет поверх этой страницы. Тестовый APK имеет идентификатор `kz.schedule.in251.fork`, поэтому устанавливается рядом с основной версией и не заменяет её. В этой ветке нет Firebase и платёжных зависимостей: HTML остаётся упакованным в APK и работает офлайн.

Для сборки в исходной рабочей папке запустите PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\android\build.ps1
```

Скрипт использует локальный Android toolchain из `work/android-toolchain`. Если он расположен в другом месте, задайте переменную `SCHEDULE_ANDROID_TOOLCHAIN`. APK и отдельная HTML-копия попадут в `dist/android/` и `dist/html/`. Закрытый ключ подписи и пароль остаются в `android/signing/` и исключены из Git.

Для публикации PWA соберите архив:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\android\package-pwa.ps1
```

Архив сайта появится в `dist/`. Распакуйте его содержимое в публикуемую папку GitHub Pages и отправьте изменения в GitHub.
