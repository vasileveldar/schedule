# Публикация расписания ИН-25-1

Этот пакет содержит макет v2 как PWA-сайт. HTML сохранён без изменений; рядом находятся манифест, иконки и офлайн-кэш.

## Публикация на GitHub Pages

1. Распакуйте архив и загрузите все файлы из него в публикуемую папку репозитория `vasileveldar/schedule`.
2. Отправьте изменения в GitHub и дождитесь публикации GitHub Pages.
3. Откройте сайт по HTTPS. После первой загрузки сервис-воркер сохранит страницу и основные ресурсы для работы офлайн.

Если сайт уже установлен на телефоне, откройте его онлайн один раз, чтобы браузер получил новую версию.
